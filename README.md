# 🛍️ Adidas US Sales Forecasting & Insights

## 📌 Project Overview
This project focuses on **sales forecasting and business insights** using Adidas US sales data. It demonstrates how to use **Big Data & Cloud Computing concepts** (AWS Lambda, S3) along with Python, Pandas, and visualization tools to automate forecasting and extract strategic insights.

## 📈 Objectives
- Forecast next month’s sales using historical monthly sales data.
- Analyze sales trends across products, regions, and channels.
- Deliver actionable business recommendations.

## 📂 Dataset
Source: *Adidas US Sales Dataset*  
Features include:
- Product Category
- Region
- Sales Method
- Units Sold
- Total Sales
- Operating Profit
- Date (Monthly Granularity)

## 🔧 Tools & Technologies
- **AWS S3 & Lambda** – For automation and storage
- **Python (Pandas, Matplotlib, Sklearn)** – For forecasting and analysis
- **Excel** – For initial data cleaning and pivot analysis
- **Google Colab** – For interactive development and execution

## 📊 Key Insights
- Highest revenue from **Men's Street Footwear** and **West Region**
- **In-store** is the dominant sales method
- **December** is the peak sales month (holiday season)

## 🧠 Forecasting Model
Used **Linear Regression** to forecast sales for January 2022 based on monthly sales trends.


## 📌 Output
Forecasted sales for **January 2022**: **$75.66M**
